# Virgin.IA — desarrollo visual local

Usa GitHub Codespaces o VS Code con el repositorio abierto. El contenedor instala las dependencias y expone el puerto 8000.

Ejecuta:

```bash
python -m virgin_ia.webapp
```

Abre el puerto reenviado **8000**. Los cambios guardados en el código se pueden comprobar inmediatamente reiniciando el servidor; para frontend estático, recarga el navegador.

No introduzcas secretos en el repositorio. Usa variables de entorno para credenciales reales.
